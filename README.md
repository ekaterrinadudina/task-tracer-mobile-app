### Мобильное приложение "Трекер задач" ###
Приложение написано в 2026 году, как учебный проект на языке Kotlin для Android.
Приложение предназначено для отслеживания задач. 
Оно позволяет их добавлять, удалять, изменять, заполнять о них информацию, смотреть статистику,
ставить уведомления и экспортировать нужную информацию. Приложение имеет виджет.
